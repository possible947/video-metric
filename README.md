# Video Metric

**Video Metric** – небольшая консольная утилита для Linux, написанная на GNU‑C, которая сравнивает два видеофайла и выводит глобальную метрику качества: **SSIM** (Structural Similarity Index) или **VMAF** (Video Multi‑Method Assessment Fusion). Утилита использует локальный `ffmpeg`, расположенный рядом с исполняемым файлом, и пред‑обученные модели VMAF, которые входят в репозиторий.

## 2. Проверка окружения

Перед выполнением любой операции утилита выводит статус проверки окружения:

```
ffmpeg: <status>, ssim: <status>, vmaf: <status>
```

`<status>` принимает значения **ok** или **fail**.

Проверка выполняет следующее:

1. **Наличие FFmpeg** – ищет бинарник `ffmpeg` в той же директории, что и `video_metric`.  
2. **Фильтры FFmpeg** – проверяет наличие фильтров `ssim` и `libvmaf`.  
3. **Модели VMAF** – убеждается в наличии файлов  
   - `model/vmaf_v0.6.1.json` (HD)  
   - `model/vmaf_4k_v0.6.1.json` (4K)  
4. **Тестовый запуск VMAF** – запускает `ffmpeg` с complex‑filtergraph`[0:v][1:v]libvmaf=log_path=vmaf.json` (используется временная папка). Если запуск завершился без ошибок, статус VMAF – **ok**.

Если `ffmpeg` отсутствует, утилита завершается сразу без выполнения дальнейших шагов.

---

## 3. Требования к локальному FFmpeg

- **Путь** – бинарник `ffmpeg` должен находиться в том же каталоге, что и `video_metric`.  
- **Версия** – любой FFmpeg, поддерживающий фильтры `ssim` и `libvmaf`.  
- **Флаги** – при расчёте SSIM используется `-threads <N>`, при VMAF – `n_threads=<N>` в фильтре `libvmaf`.

---

## 4. Требования к моделям VMAF

- `model/vmaf_v0.6.1.json` – модель для HD (1080p).  
- `model/vmaf_4k_v0.6.1.json` – модель для 4K (2160p).  
- Файлы автоматически копируются в репозиторий; при сборке они остаются в каталоге `model/`.  
- При расчёте VMAF утилита выбирает модель в зависимости от флага `-r` (`hd` по умолчанию, `4k` при указании).

---

## 5. Обработка путей

Утилита корректно обрабатывает:

- пробелы, кавычки, символы UTF‑8;  
- escape‑последовательности (например, `\n`, `\t`, `\\`);  
- пути, перетаскиваемые из файловых менеджеров Nautilus.  

Все пути, передаваемые в вызов `ffmpeg`, заключаются в двойные кавычки и экранируются функцией `escape_path`.

## 6. Вычисление метрик

### 6.1 SSIM

Команда, которую запускает утилита:

```bash
./ffmpeg -i "<original>" -i "<test>" -vf "ssim" -f null - -threads <N>
```

`<N>` – число потоков (`-n`), если указано.  

Фильтр выводит одну строку вида:

```
SSIM ... All:<значение>
```

Утилита извлекает `<значение>` и выводит в формате:

```
SSIM: <значение>
```

### 6.2 VMAF

Команда, которую запускает утилита:

```bash
./ffmpeg -i "<original>" -i "<test>" \
-filter_complex "[0:v][1:v]libvmaf=model=path=<model_path>:n_threads=<N>:log_path=<tmp_dir>/vmaf.json" \
-f null - -threads <N>
```

`<model_path>` – путь к модели (HD или 4K).  
`<tmp_dir>` – временная директория, созданная в момент расчёта.  

Фильтр выводит строку:

```
VMAF score: <значение>
```

Утилита извлекает `<значение>` и выводит в формате:

```
VMAF: <значение>
```

## 7. Формат запуска

```
./video_metric [OPTIONS]
```

### Опции

| Флаг | Псевдоним | Описание |
|------|----------|----------|
| `-o` | `--output` | Путь к оригинальному видео |
| `-t` | `--test`   | Путь к проверяемому видео |
| `-s` | `--ssim`   | Вычислить SSIM |
| `-v` | `--vmaf`   | Вычислить VMAF |
| `-r` | `--resolution` | `hd` (по умолчанию) или `4k` (только для VMAF) |
| `-n` | `--num_threads` | Число потоков для FFmpeg (`-threads`) и для фильтра `libvmaf` (`n_threads`) |

- Если одновременно указаны `-s` и `-v`, утилита вычислит обе метрики.  
- Если указан флаг `-s` вместе с `-r`, флаг `-r` игнорируется.  
- При отсутствии `-s` и `-v` утилита завершает работу с сообщением об ошибке.  

### Примеры

```bash
# SSIM для двух видео
./video_metric -o video_orig.mp4 -t video_test.mp4 -s

# VMAF для HD (по умолчанию) с 4 потоками
./video_metric -o video_orig.mp4 -t video_test.mp4 -v -n 4

# VMAF для 4K с 8 потоками
./video_metric -o video_orig_4k.mp4 -t video_test_4k.mp4 -v -r 4k -n 8

# Оба метрики одновременно
./video_metric -o video_orig.mp4 -t video_test.mp4 -s -v
```
