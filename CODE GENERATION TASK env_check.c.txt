Purpose:
Verify the runtime environment before any metric calculations: check for local FFmpeg, required filters, VMAF model files, and perform a test VMAF launch to confirm functionality.

Context Summary:
`env_check.c` is invoked from `main.c` early in the program. It must populate a status string of the form:
```

```
where each `<status>` is either `ok` or `fail`.  
The function should also return a non‑zero code if any of the required components are missing, causing `main.c` to exit immediately.

  ffmpeg -filters | grep -q "ssim"

- Test if the `ffmpeg` binary supports the `libvmaf` filter by running:

  ffmpeg -filters | grep -q "libvmaf"
```
  Capture exit status.

- Build the status string in a buffer provided by the caller (`char *status_buf, size_t bufsize`).  
  Ensure the string is null‑terminated and does not overflow.
- Return `0` if all checks pass, otherwise return `-1`.
