# **СПЕЦИФИКАЦИЯ ПРОЕКТА**

## **Назначение**

Создать консольную утилиту для Linux, которая вычисляет метрики **SSIM** или **VMAF**, сравнивая два видеофайла.

---

## **Параметры запуска**

- `-o`, `--output` — оригинальный файл  
- `-t`, `--test` — проверяемый файл  
- `-s`, `--ssim` — вычисление SSIM  
- `-v`, `--vmaf` — вычисление VMAF  
- `-r`, `--resolution` — `hd` или `4k`  
- `-n`, `--num_threads`  
  - для SSIM → передаётся в `ffmpeg -threads`  
  - для VMAF → передаётся в `n_threads=<N>` внутри фильтра `libvmaf`

---

## **Компиляция**

Проект обязан использовать GNU‑режим:

- `-std=gnu11`  
- `-D_GNU_SOURCE`  
- `-Wall -Wextra -O2 -D_FORTIFY_SOURCE=2 -fstack-protector-strong`

Запрещено использовать стандарты C99/C11/ANSI.

---

## **Использование локального FFmpeg**

Утилита обязана использовать **локальный FFmpeg**, расположенный рядом с бинарником:

```
video_metric/
 ├── video_metric
 ├── ffmpeg
 └── model/
      ├── vmaf_v0.6.1.json
      └── vmaf_4k_v0.6.1.json
```

## **Проверка окружения**

Перед выполнением любых операций утилита выводит строку:

```
ffmpeg: <status>, ssim: <status>, vmaf: <status>
```

Проверяется:

- фильтр `libvmaf`

Если FFmpeg отсутствует → завершить работу.

## **SSIM**

Команда:

```
-vf "ssim"
```

Фильтр выводит **одну итоговую строку**:

```
SSIM ... All:<значение>
```

Используется только `All`.  
SSIM — **глобальная метрика**.  
`min = max = avg = All`.

---

## **VMAF**

Обязателен complex‑filtergraph:

```
-filter_complex "[0:v][1:v]libvmaf=..."
```

HD:

```
-filter_complex "[0:v][1:v]libvmaf=model=path=<model>:n_threads=<N>:log_path=vmaf.json"
```

4K:

```
-filter_complex "[0:v][1:v]libvmaf=model=path=<model_4k>:n_threads=<N>:log_path=vmaf.json"
```

Фильтр выводит **одну итоговую строку**:

```
VMAF score: <значение>
```

VMAF — **глобальная метрика**.  
`min = max = avg = <значение>`.  
JSON‑лог используется только для проверки успешности.
